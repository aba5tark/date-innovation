# Милое приглашение на свидание 💌

Небольшой Flask-сайт с двумя вариантами ответа, анимацией сердечек, QR-кодом страницы и уведомлением в Telegram. Токен бота хранится только в переменных окружения сервера и не отправляется в браузер.

## 1. Создайте Telegram-бота

1. Откройте Telegram и найдите **@BotFather**.
2. Отправьте `/newbot`, задайте имя и username бота.
3. Скопируйте выданный токен. **Не публикуйте его и не отправляйте никому.**
4. Откройте своего нового бота и нажмите **Start** (или отправьте `/start`).

## 2. Узнайте свой Telegram chat ID

После того как вы нажали Start у своего бота, откройте в браузере адрес, заменив `ВАШ_ТОКЕН` на токен:

`https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`

В ответе найдите фрагмент `"chat":{"id":123456789,...}`. Число после `"id"` — ваш `TELEGRAM_CHAT_ID`. Если обновлений нет, отправьте боту `/start` ещё раз и обновите страницу. Не делитесь ссылкой на `getUpdates`: в ней находится секретный токен.

## 3. Опубликуйте сайт бесплатно на Render

1. Распакуйте архив.
2. Создайте репозиторий на GitHub и загрузите в него файлы проекта.
3. Войдите на [Render](https://render.com/), выберите **New + → Blueprint** и подключите репозиторий с файлом `render.yaml`.
4. Render обнаружит конфигурацию. В настройках сервиса добавьте значения переменных окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_CHAT_ID` — ваш числовой chat ID.
5. Запустите деплой и дождитесь статуса **Live**. Render выдаст URL примерно вида `https://имя-сервиса.onrender.com` (ваш точный адрес будет другим).
6. Откройте URL. QR-код находится внизу страницы под пунктом **«Показать QR-код этой странички»**. Скачайте/сохраните его или сделайте скриншот и отправьте девушке.

QR-код строится из реального URL, на котором открыт сайт. Если домен изменится, откройте новый адрес и используйте новый QR-код.

## 4. Проверка

1. Откройте опубликованный сайт.
2. Нажмите одну из кнопок ответа.
3. В чат с вашим ботом должно прийти сообщение с выбранным вариантом.

## Локальный запуск (необязательно)

Нужен Python 3.10+:

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt

# macOS/Linux:
export TELEGRAM_BOT_TOKEN="токен_от_BotFather"
export TELEGRAM_CHAT_ID="ваш_chat_id"
# Windows PowerShell:
# $env:TELEGRAM_BOT_TOKEN="токен_от_BotFather"
# $env:TELEGRAM_CHAT_ID="ваш_chat_id"

python app.py
```

Откройте `http://127.0.0.1:5000`. QR-код локального запуска ведёт на локальный адрес и с телефона девушки работать не будет; для реального приглашения нужен опубликованный URL.

## Важные заметки

- Пока переменные окружения не настроены, сайт покажет сообщение об ошибке при отправке ответа, а не будет притворяться, что уведомление отправлено.
- Не вставляйте токен в HTML, JavaScript, GitHub или QR-код.
- На бесплатных тарифах хостинга сервис может «засыпать» после простоя, поэтому первое открытие иногда занимает время.
- Сайт отправляет в ваш Telegram только выбранный ответ. Он не собирает имя или местоположение посетителя.
